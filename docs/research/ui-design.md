## 0. Decisions in one screen

| Topic | Decision |
|---|---|
| Deployment target | **macOS 26.0** for both targets. The SDK is 27.2, so it also has macOS 27 APIs, but the user runs 26.6.2. **Don't call any `macOS 27` API** (`NSGlassEffectView.effectIsInteractive`, `NSViewCornerConfiguration`, `NSMenuItem.preferredImageVisibility`, …). Put an `#available(macOS 26.1, *)` check around the 26.1 APIs: `.buttonStyle(.glass(.clear))`, which uses `GlassButtonStyle.init(_:)`, and `NSScrollEdgeEffectStyle`. |
| HUD glass | SwiftUI `.glassEffect(.regular, in: .capsule)` inside a **clear, borderless, non-activating `NSPanel`**. Verified by capture: the glass picks up the content of *other windows behind the panel* in both light and dark. `NSGlassEffectView` as the panel's `contentView` also works and is the AppKit fallback. |
| HUD window | `[.borderless, .nonactivatingPanel]`, level `CGShieldingWindowLevel()` (2147483628, above menus at 101 and Spotlight, as in rime/Squirrel), `[.canJoinAllSpaces, .fullScreenAuxiliary, .transient, .ignoresCycle]`, `ignoresMouseEvents = true`, `hidesOnDeactivate = false`, `canBecomeKey/Main = false`, shown with `orderFrontRegardless()`. **Never** activate the IME app. |
| HUD placement | A pure function (`HUDGeometry.place`, unit-tested with Swift Testing, 7/7 pass). It aligns to the IMK caret rect, flips above the caret near the bottom edge, clamps to `visibleFrame`, picks the display that contains the caret, snaps to the backing scale, and hides on a garbage rect. |
| Host app | One sidebar `Window` that looks like System Settings (`NavigationSplitView` + `Form.formStyle(.grouped)`), with ⌘, rebound to it. A separate onboarding `Window` with a hidden title bar runs 4 steps. Buttons are `.glass` / `.glassProminent`. |
| App icon | An **Icon Composer `.icon` bundle generated from code**: hand-built SVG geometry with no font outlines, so there's no licence issue. `actool` compiles it to `Assets.car` + `AppIcon.icns`, and with XcodeGen 2.46 you just list it under `sources` (verified end-to-end). Concept: two overlapping keycaps, a warm one with "가" and a cool one with "A". |
| Input-source icon | A 16×16 pt **template TIFF** (16 px @72 dpi + 32 px @144 dpi reps), black + alpha, with `TISIconIsTemplate = true`. This is the same format as Apple's own `KoreanIM`. Generated by code. |
| Visual QA without TCC | `ImageRenderer` **drops glass views entirely**, so use a snapshot stand-in. `cacheDisplay` works for Forms and controls if the window is parked off-screen and ordered in. **ScreenCaptureKit capture of our own windows worked in this session** (`CGPreflightScreenCaptureAccess() == true`, real Liquid Glass captured). ## 2. Composition HUD

### 2.1 Behaviour

The marked text in the client app shows Duo's best guess (for example `안녕`). The HUD is a small glass chip just under the caret.
It shows **the other interpretation** (`dkssud`), a badge for that interpretation's language, and a key-cap hint for the flip key.
Pressing the flip key swaps the two.

| Event | HUD reaction |
|---|---|
| Composition starts (1st key) | Stays hidden for 1-key words. Show from the **2nd keystroke**, or immediately if the auto-detector has already flipped. This avoids noise on "a", "I", "ㅋ". |
| Each keystroke | The text updates **instantly**, with no per-keystroke animation, like Apple's own candidate UI. The panel is re-measured (`fittingSize` updates synchronously, verified) and re-placed. |
| Auto-detector flips language mid-word (e.g. `rk` → `가`) | The badge glyph changes with the SF Symbols *replace* transition (`character` ↔ `character.ko`, `.replace.downUp`). The chip makes **one** micro-pulse: scale 1.00→1.04→1.00, leading anchor, spring 0.18 s up and 0.32 s settle, plus a 25 % accent tint on the glass for the duration. No sound, no motion of the panel itself. |
| User presses flip key | The inline text and the chip text swap. The chip text uses `.contentTransition(.interpolate)` with spring(0.28 s, bounce 0.12). |
| Commit (space, punctuation, return, click) / Esc | Hide after a **140 ms debounce**, then a 100 ms ease-in fade. If a new word starts within the debounce, the HUD just moves, so continuous typing never blinks. |
| `deactivateServer`, client switch, caret rect unusable | `orderOut` immediately, with no animation. |
| First show | A 140 ms ease-out alpha fade-in (80 ms with Reduce Motion). No scale or slide. |

### 2.2 Anatomy & metrics (points)

```
 ┌────────────────────────────────────────────┐  ← capsule, height 28, Liquid Glass .regular
 │ (A)  dkssud   [⇧][Space]                   │
 └────────────────────────────────────────────┘
  ↑4  ↑20 badge ↑6 gap  text 14pt medium  ↑6  keycaps 16pt-high, 10pt rounded semibold  ↑4 trailing (10 when no hint)
```

* Chip height **28**. Leading padding **4** (the badge sits concentric inside the capsule). Inner spacing **6**. Trailing padding **4**, or **10** when the hint is hidden.
* Badge: a **20** pt circle filled `Color.blue` for English or `Color.orange` for 한국어. It holds the SF Symbol `character` ("A") or `character.ko` ("가"), 11 pt semibold, white. These are system colors, so they adapt to Dark Mode and Increase Contrast automatically.
* Text: SF Pro 14 pt medium, `.primary`, one line, `fixedSize`. Hangul falls back to Apple SD Gothic Neo automatically.
* Key caps: SF Pro Rounded 10 pt semibold, `.secondary`, `RoundedRectangle(cornerRadius: 4, style: .continuous)` filled `primary.opacity(0.08)` (0.14 with Reduce Transparency), min 16×16, 4 pt horizontal padding, 2 pt gap between caps.
* Placement: **5 pt** below the caret line box. The chip's leading edge sits **8 pt left of the marked-text start**. Keep **6 pt** away from `visibleFrame` edges. There's an **8 pt** transparent margin inside the panel for the glass shadow and the pulse overshoot.
* Window shadow is off (`hasShadow = false`), because glass draws its own shadow and a window shadow would be rectangular.

### 2.3 Accessibility

* **Reduce Motion** (`@Environment(\.accessibilityReduceMotion)` / `NSWorkspace.shared.accessibilityDisplayShouldReduceMotion`): no pulse and no scale. Badge and text change by opacity cross-fade only. The fade-in is 80 ms.
* **Reduce Transparency / Increase Contrast**: system glass adapts by itself (it frosts and gains a stronger edge). On top of that we raise the key-cap fill opacity, and with `colorSchemeContrast == .increased` we stroke the capsule with a 1 pt `primary.opacity(0.55)` hairline. The snapshot at `out/snapshot-dark-hc.png` verifies this.
* **Dark / Light**: no hard-coded colors. Captured in both modes over mixed backdrops (§2.8).
* **VoiceOver**: the chip is a single element with label "English alternative" / "Korean alternative" and value = the text. Don't announce every keystroke. Optionally, only when `NSWorkspace.shared.isVoiceOverEnabled`, post a low-priority `NSAccessibility.post(element:notification: .announcementRequested, userInfo: [.announcement: "…", .priority: NSAccessibilityPriorityLevel.low.rawValue])` on an auto-flip.

### 2.4 Positioning rules (feed it the IMK caret rect)

* Get the rect from `client.attributes(forCharacterIndex: 0, lineHeightRectangle: &rect)`, which gives the start of the marked text in **Cocoa global coordinates** (origin at the bottom-left of `NSScreen.screens[0]`, y up). Pass it as is, with **no flipping**.
* Clients sometimes return `.zero`: hide. A height of 0 is treated as 16 pt. A rect on no display is retried flipped around the primary display's height (this catches clients that return top-left-origin y), and otherwise hidden.
* Screen selection uses `frame.contains(caret.origin)`, not `NSScreen.main` (which is the key window's screen, and that may not be the client's).
* Prefer **below** the caret. If the chip would cross `visibleFrame.minY` (Dock), put it **above** (`caret.maxY + 5`). Clamp x and y into `visibleFrame.insetBy(6)`.
* Snap the origin to `1/backingScaleFactor`, so text stays crisp while the panel moves.
* Re-place on every update. Don't animate the window frame (`animate: false`); NSWindow frame animation is janky and lags typing.

### 2.5 Code — geometry (pure, Sendable, unit-tested) — verified

```swift
import CoreGraphics

/// Pure, testable placement math for the composition HUD.
/// All rects are in Cocoa *global* screen coordinates: origin at the bottom-left of the
/// primary display (NSScreen.screens[0]), y grows upward — the space IMK returns from
/// `IMKTextInput.attributes(forCharacterIndex:lineHeightRectangle:)`.
public struct HUDScreen: Sendable, Equatable {
    public var frame: CGRect          // NSScreen.frame
    public var visibleFrame: CGRect   // NSScreen.visibleFrame (minus menu bar + Dock)
    public var scale: CGFloat         // NSScreen.backingScaleFactor
    public init(frame: CGRect, visibleFrame: CGRect, scale: CGFloat) {
        self.frame = frame; self.visibleFrame = visibleFrame; self.scale = scale
    }
}

public struct HUDPlacement: Sendable, Equatable {
    public enum Edge: Sendable, Equatable { case below, above }
    /// Frame of the chip itself (the visible glass capsule), global coords.
    public var chipFrame: CGRect
    /// Frame for the (larger, transparent) NSPanel that hosts the chip + shadow margin.
    public var panelFrame: CGRect
    public var edge: Edge
}

public enum HUDGeometry {
    /// Vertical gap between the caret line box and the chip.
    public static let gap: CGFloat = 5
    /// Keep the chip this far from visibleFrame edges.
    public static let screenMargin: CGFloat = 6
    /// The chip's leading edge sits this far left of the caret so the text column
    /// inside the chip (after the 20pt badge + 6pt spacing + 8pt padding) visually
    /// starts near the marked-text start. Tuned for a 28pt-high chip.
    public static let leadingOutset: CGFloat = 8

    /// - Parameters:
    ///   - caret: line-height rect of the *start* of the marked text (character index 0).
    ///   - chipSize: SwiftUI fitting size of the chip.
    ///   - margin: transparent margin around the chip inside the panel (room for shadow & spring overshoot).
    ///   - screens: NSScreen.screens mapped to HUDScreen, index 0 = primary.
    /// - Returns: nil when the caret rect is unusable (hide the HUD).
    public static func place(caret rawCaret: CGRect,
                             chipSize: CGSize,
                             margin: CGFloat,
                             screens: [HUDScreen]) -> HUDPlacement? {
        guard !screens.isEmpty,
              rawCaret.origin.x.isFinite, rawCaret.origin.y.isFinite,
              !(rawCaret.origin == .zero && rawCaret.size == .zero) else { return nil }

        var caret = rawCaret
        if caret.height < 1 { caret.size.height = 16 }   // some clients return 0-height rects
        let probe = CGPoint(x: caret.minX, y: caret.midY)

        // 1. Screen that contains the caret. 2. Heuristic for clients that hand back
        // *flipped* (top-left origin) coordinates: flip around the primary display height.
        var screen = screens.first { $0.frame.contains(probe) }
        if screen == nil {
            let primaryHeight = screens[0].frame.height
            var flipped = caret
            flipped.origin.y = primaryHeight - caret.maxY
            if let s = screens.first(where: { $0.frame.contains(CGPoint(x: flipped.minX, y: flipped.midY)) }) {
                caret = flipped; screen = s
            }
        }
        // Still nowhere on any display => the client handed us garbage; hide rather than guess.
        guard let screen = screen ?? screens.first(where: { $0.frame.intersects(caret) }) else { return nil }
        let vis = screen.visibleFrame.insetBy(dx: screenMargin, dy: screenMargin)

        // Horizontal: align to caret, clamp into the visible frame.
        var x = caret.minX - leadingOutset
        x = min(max(x, vis.minX), vis.maxX - chipSize.width)

        // Vertical: prefer below the line; flip above when it would leave the visible frame.
        var edge = HUDPlacement.Edge.below
        var y = caret.minY - gap - chipSize.height
        if y < vis.minY {
            edge = .above
            y = caret.maxY + gap
        }
        y = min(max(y, vis.minY), vis.maxY - chipSize.height)

        // Snap to the backing pixel grid of the target display (crisp text, no shimmer while moving).
        func snap(_ v: CGFloat) -> CGFloat { (v * screen.scale).rounded() / screen.scale }
        let chip = CGRect(x: snap(x), y: snap(y), width: chipSize.width, height: chipSize.height)
        let panel = chip.insetBy(dx: -margin, dy: -margin)
        return HUDPlacement(chipFrame: chip, panelFrame: panel, edge: edge)
    }
}
```

### 2.6 Code — view, panel, controller (Swift 6 strict, compiles warning-free) — verified

```swift
import AppKit
import SwiftUI
import Observation

// MARK: - Model (owned by the input controller, mutated on the main actor)

public enum DuoScript: String, Sendable, Equatable {
    case hangul, latin
}

@MainActor
@Observable
public final class CompositionHUDModel {
    /// The *other* interpretation of the keys typed so far (what flipping would produce).
    public var alternative: String = ""
    /// Script of `alternative` (so the badge shows "A" while the inline text is Hangul).
    public var alternativeScript: DuoScript = .latin
    /// Key-cap glyphs for the flip key, e.g. ["⇧", "Space"] or ["⌘"] (right command tap).
    public var flipKeyCaps: [String] = ["⇧", "Space"]
    /// Bumped by the controller whenever auto-detection flips the inline language mid-word.
    public var autoFlipCount: Int = 0
    /// Bumped when the user presses the flip key (manual flip).
    public var manualFlipCount: Int = 0
    public var showsKeyHint: Bool = true

    public init() {}
}

// MARK: - SwiftUI chip

public struct CompositionHUDView: View {
    let model: CompositionHUDModel

    @Environment(\.accessibilityReduceMotion) private var reduceMotion
    @Environment(\.accessibilityReduceTransparency) private var reduceTransparency
    @Environment(\.colorSchemeContrast) private var contrast
    @Environment(\.colorScheme) private var colorScheme
    @State private var pulse = false

    public init(model: CompositionHUDModel) { self.model = model }

    public var body: some View {
        HStack(spacing: 6) {
            badge
            Text(model.alternative)
                .font(.system(size: 14, weight: .medium))
                .monospacedDigit()
                .lineLimit(1)
                .fixedSize()
                .foregroundStyle(.primary)
                .contentTransition(reduceMotion ? .opacity : .interpolate)
                .animation(reduceMotion ? nil : .spring(duration: 0.28, bounce: 0.12), value: model.manualFlipCount)
            if model.showsKeyHint {
                keyHint
                    .transition(.opacity)
            }
        }
        .padding(.leading, 4)
        .padding(.trailing, model.showsKeyHint ? 4 : 10)
        .frame(height: 28)
        .duoGlass(glass, in: Capsule())
        .overlay {
            // Increase Contrast: glass already gains a stronger edge; add a crisp 1px hairline anyway.
            if contrast == .increased {
                Capsule().strokeBorder(Color.primary.opacity(0.55), lineWidth: 1)
            }
        }
        .scaleEffect(pulse && !reduceMotion ? 1.04 : 1, anchor: .leading)
        .onChange(of: model.autoFlipCount) {
            guard !reduceMotion else { return }
            withAnimation(.spring(duration: 0.18, bounce: 0.4)) { pulse = true } completion: {
                withAnimation(.spring(duration: 0.32, bounce: 0.2)) { pulse = false }
            }
        }
        .accessibilityElement(children: .ignore)
        .accessibilityLabel(Text(model.alternativeScript == .latin ? "English alternative" : "Korean alternative"))
        .accessibilityValue(Text(model.alternative))
    }

    private var glass: Glass {
        // A whisper of tint while the auto-flip pulse is active; nothing otherwise.
        pulse ? .regular.tint(Color.accentColor.opacity(0.25)) : .regular
    }

    /// 20pt circle with "A" / "가": tells the user which language the chip would give them.
    private var badge: some View {
        Image(systemName: model.alternativeScript == .latin ? "character" : "character.ko")
            .font(.system(size: 11, weight: .semibold))
            .foregroundStyle(.white)
            .frame(width: 20, height: 20)
            .background(Circle().fill(model.alternativeScript == .latin ? Color.blue : Color.orange))
            .contentTransition(reduceMotion ? .opacity : .symbolEffect(.replace.downUp))

private struct DuoGlassModifier<S: InsettableShape>: ViewModifier {
    let glass: Glass
    let shape: S
    @Environment(\.duoSnapshotMode) private var snapshot
    func body(content: Content) -> some View {
        if snapshot {
            content
                .background(shape.fill(.background.secondary))
                .overlay(shape.strokeBorder(.separator, lineWidth: 0.5))
                .shadow(color: .black.opacity(0.18), radius: 6, y: 2)
        } else {
            content.glassEffect(glass, in: shape)
        }
    }
}

extension View {
    func duoGlass<S: InsettableShape>(_ glass: Glass = .regular, in shape: S) -> some View {
        modifier(DuoGlassModifier(glass: glass, shape: shape))
    }
}

// MARK: - Controller

@MainActor
public final class CompositionHUDController {
    public let model = CompositionHUDModel()
    private let panel = CompositionHUDPanel()
    private let hosting: NSHostingView<AnyView>
    private var hideTask: Task<Void, Never>?
    private var isShown = false
    public static let margin: CGFloat = 8

    public init() {
        hosting = NSHostingView(rootView: AnyView(EmptyView()))
        hosting.rootView = AnyView(
            CompositionHUDView(model: model)
                .padding(Self.margin)
        )
        hosting.sizingOptions = [.intrinsicContentSize]
        panel.contentView = hosting
    }

    /// Call after every keystroke that changes the composition.
    /// - Parameter caret: IMK line-height rect for character index 0 of the marked text.
    public func update(alternative: String, script: DuoScript, caret: NSRect) {
        hideTask?.cancel()
        model.alternative = alternative
        model.alternativeScript = script
        guard !alternative.isEmpty else { hide(); return }

        hosting.layoutSubtreeIfNeeded()
        let fit = hosting.fittingSize
        let chipSize = CGSize(width: fit.width - 2 * Self.margin, height: fit.height - 2 * Self.margin)
        let screens = NSScreen.screens.map {
            HUDScreen(frame: $0.frame, visibleFrame: $0.visibleFrame, scale: $0.backingScaleFactor)
        }
        guard let placement = HUDGeometry.place(caret: caret, chipSize: chipSize,
                                                margin: Self.margin, screens: screens) else {
            hide(); return
        }
        panel.setFrame(placement.panelFrame, display: true, animate: false)
        if !isShown {
            isShown = true
            panel.alphaValue = 0
            panel.orderFrontRegardless()          // our IME process is never the active app
            let reduceMotion = NSWorkspace.shared.accessibilityDisplayShouldReduceMotion
            NSAnimationContext.runAnimationGroup { ctx in
                ctx.duration = reduceMotion ? 0.08 : 0.14
                ctx.timingFunction = CAMediaTimingFunction(name: .easeOut)
                panel.animator().alphaValue = 1
            }
        }
    }

    /// Call on commit / cancel. Debounced so continuous typing across word boundaries doesn't blink.
    public func hide(after delay: Duration = .milliseconds(140)) {
        hideTask?.cancel()
        hideTask = Task { [weak self] in
            try? await Task.sleep(for: delay)
            guard let self, !Task.isCancelled else { return }
            self.isShown = false
            NSAnimationContext.runAnimationGroup({ ctx in
                ctx.duration = 0.10
                ctx.timingFunction = CAMediaTimingFunction(name: .easeIn)
                self.panel.animator().alphaValue = 0
            }, completionHandler: { [weak self] in
                MainActor.assumeIsolated {
                    guard let self, !self.isShown else { return }
                    self.panel.orderOut(nil)
                }
            })
        }
    }

    public func noteAutoFlip() { model.autoFlipCount &+= 1 }
    public func noteManualFlip() { model.manualFlipCount &+= 1 }
}
```

Notes:
* `CompositionHUDController.update(...)` mutates the `@Observable` model and then reads `hosting.fittingSize` **in the same turn**. I verified that the size is already up to date synchronously, for example `"dk"` → 132.5 and `"dkssudgktpdy"` → 210.5, with an identical value after a run-loop turn.
* The IME process is never the active app. `orderFrontRegardless()` is required, and `NSApp.activate` must never be called, because it would steal focus from the client and break input.
* Alternative layout: a fixed, large transparent panel with the chip positioned by SwiftUI. It also renders correctly, since glass samples behind-window content. It's rejected because a panel that straddles two displays with "Displays have separate Spaces" turned on is shown only on the display with the larger share, which could hide the chip. Resize-to-fit avoids that.
* Optional polish: tint the marked-text underline with the language color via IMK `mark(forStyle:at:)` attributes. Many clients ignore underline color, so treat it as nice-to-have.

### 2.7 Snapshot/glass stand-in

`ImageRenderer` drops any view that carries `.glassEffect`, content included (verified: only the backdrop came out). The HUD therefore routes glass
through `duoGlass(_:in:)`, which swaps in an opaque capsule (`.background.secondary` + `.separator` stroke + shadow) when
`\.duoSnapshotMode == true`. That allows pixel tests of layout, typography, truncation, Dark Mode and Increase Contrast with `ImageRenderer`
in any headless test.

## 3. Host app "Duo" (in /Applications)

### 3.1 Scene structure

The host app's only job is configuration, so it works the way System Settings does: **one sidebar window**. The app menu's "Settings…" (⌘,) opens that same window, so there's no duplicate settings window. The standard About panel stays in the app menu, and the About pane mirrors it.

## 4. Icons

### 4.1 Icon Composer `.icon` format (schema from a shipping bundle, validated by rendering)

A `.icon` is a **folder**:

```
AppIcon.icon/
  icon.json
  Assets/            ← SVG (preferred, 1024×1024 viewBox) or PNG (1024 px) layer art; referenced by file name
```

`icon.json` keys, taken from `/Applications/LINE.app/Contents/Resources/LiquidGlass_LINE.icon` and from my generated file, which `ictool` and `actool` both accepted:

```text
root:
  fill | fill-specializations          background: "automatic" | {"solid": COLOR} | {"linear-gradient": [COLOR, COLOR]}
  groups: [GROUP]                      groups[0] is the TOP-most
  supported-platforms: {"squares": "shared" | ["macOS", "iOS", ...], "circles": ["watchOS"]}
GROUP:
  name, hidden (bool), layers: [LAYER] (layers[0] top-most)
  lighting: "individual" | "combined"
  shadow | shadow-specializations      {"kind": "neutral" | "layer-color" | "none", "opacity": 0...1}
  translucency | translucency-specializations   {"enabled": bool, "value": 0...1}
  specular | specular-specializations  bool
  blur-material | blur-material-specializations number | null
  blend-mode | blend-mode-specializations       "normal" | "multiply" | ...
  opacity, position {"scale": n, "translation-in-points": [x, y]}
LAYER:
  name, image-name (file in Assets/), hidden
  fill | fill-specializations          "automatic" | {"solid": COLOR} | {"linear-gradient": [...]}  (recolours the SVG)
  glass | glass-specializations        bool  (Liquid Glass on this layer)
  opacity | opacity-specializations, blend-mode(-specializations), position
SPECIALIZATION array element: {"appearance": "dark" | "tinted" | (absent = default/light), "value": ...}
COLOR string: "srgb:r,g,b,a" or "display-p3:r,g,b,a" (0...1 floats, 5 decimals in Apple's output)
```

### 4.2 Toolchain (verified)

* `ictool` is at `/Applications/Xcode.app/Contents/Applications/Icon Composer.app/Contents/Executables/ictool` (version 27.2). It renders previews headlessly:
  `ictool AppIcon.icon --export-image --output-file out.png --platform macOS --rendition Default|Dark|TintedLight|TintedDark|ClearLight|ClearDark --width 512 --height 512 --scale 1 [--design-generation 26|27]`.
  It prints `{}` on success. I rendered all six renditions and looked at them.
* `actool` compiles the `.icon` directly. `xcrun actool AppIcon.icon --compile OUT --platform macosx --minimum-deployment-target 26.0 --app-icon AppIcon --output-partial-info-plist p.plist` produces `Assets.car` (1.9 MB) plus **`AppIcon.icns`** (the legacy fallback is generated automatically) and adds `CFBundleIconFile`/`CFBundleIconName = AppIcon` to the plist.
* **XcodeGen 2.46.0**: put `AppIcon.icon` anywhere under a target's `sources` path. It's emitted as `lastKnownFileType = wrapper.icon` in the Resources phase, and with `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon` Xcode's build runs `actool …/AppIcon.icon --app-icon AppIcon`. I verified this with a probe project: **BUILD SUCCEEDED**, and the `.app` contains `AppIcon.icns` + `Assets.car`, with Info.plist icon keys set. Do **not** put the `.icon` inside `Assets.xcassets`. An `Assets.xcassets` (for AccentColor and so on) can live alongside it.
* Fallback if it's ever needed: `Assets.xcassets/AppIcon.appiconset` with 10 PNGs (16, 32, 128, 256, 512 at @1x/@2x, i.e. 16…1024 px) and a `Contents.json` using `"idiom":"mac"`. Generate the PNGs with `ictool --rendition Default --width N --height N --scale 1|2`. Not needed for a 26.0 target.

### 4.3 Concept & artwork

**"Two keycaps"**: a warm orange rounded-square keycap carrying **가** sits behind and upper-left. A cool blue keycap carrying **A** overlaps it lower-right.

specular highlights, layer-colour shadows, combined lighting, and slight translucency, so the overlap reads as glass on glass.

```swift
// Generates Duo's artwork from code — no hand-made binaries, no font outlines (license-clean):
//   1. AppIcon.icon/            Icon Composer bundle (icon.json + Assets/*.svg)
//   2. DuoMenuIcon.tiff         16x16@1x + 32x32@2x template TIFF for the input-source menu
// Usage: swift GenerateIcons.swift <outdir>
import AppKit
import CoreGraphics

// MARK: Geometry (SVG space: 1024x1024, y grows DOWN)

/// "가" as rounded strokes: ㄱ (bar + sweeping descender) and ㅏ (stem + tick).
func hangulGa(center c: CGPoint, scale s: CGFloat) -> CGPath {
    let p = CGMutablePath()
    func pt(_ x: CGFloat, _ y: CGFloat) -> CGPoint { CGPoint(x: c.x + x * s, y: c.y + y * s) }
    // ㄱ
    p.move(to: pt(-112, -78))
    p.addLine(to: pt(-14, -78))
    p.addQuadCurve(to: pt(-96, 100), control: pt(-14, 40))
    // ㅏ
    p.move(to: pt(48, -118))
    p.addLine(to: pt(48, 118))
    p.move(to: pt(48, -2))
    p.addLine(to: pt(112, -2))
    return p
}

/// "A" as rounded strokes.
func latinA(center c: CGPoint, scale s: CGFloat) -> CGPath {
    let p = CGMutablePath()
    func pt(_ x: CGFloat, _ y: CGFloat) -> CGPoint { CGPoint(x: c.x + x * s, y: c.y + y * s) }
    p.move(to: pt(-92, 112))
    p.addLine(to: pt(0, -112))
    p.addLine(to: pt(92, 112))
    p.move(to: pt(-56, 40))
    p.addLine(to: pt(56, 40))
    return p
}

func outline(_ path: CGPath, width: CGFloat) -> CGPath {
    path.copy(strokingWithWidth: width, lineCap: .round, lineJoin: .round, miterLimit: 10)
        .normalized()   // merge overlaps (macOS 13+) so nonzero fill never punches holes
}

func roundedTile(_ rect: CGRect, radius: CGFloat) -> CGPath {

// MARK: SVG emission

func svgPathData(_ path: CGPath) -> String {
    var d = ""
    func f(_ v: CGFloat) -> String { String(format: "%.2f", v) }
    path.applyWithBlock { el in
        let e = el.pointee, p = e.points
        switch e.type {
        case .moveToPoint: d += "M\(f(p[0].x)) \(f(p[0].y))"
        case .addLineToPoint: d += "L\(f(p[0].x)) \(f(p[0].y))"
        case .addQuadCurveToPoint: d += "Q\(f(p[0].x)) \(f(p[0].y)) \(f(p[1].x)) \(f(p[1].y))"
        case .addCurveToPoint: d += "C\(f(p[0].x)) \(f(p[0].y)) \(f(p[1].x)) \(f(p[1].y)) \(f(p[2].x)) \(f(p[2].y))"
        case .closeSubpath: d += "Z"
        @unknown default: break
        }
    }
    return d
}

func svg(_ path: CGPath) -> String {
    """
    <svg width="1024" height="1024" viewBox="0 0 1024 1024" fill="none" xmlns="http://www.w3.org/2000/svg">
    <path d="\(svgPathData(path))" fill="white"/>
    </svg>

    """
}
```

What Apple ships (read from `/System/Library/Input Methods/KoreanIM.app/Contents/PlugIns/KIM_Extension.appex` and `TamilIM.app`):

```swift
import AppKit
import SwiftUI

@MainActor
func snapshot<V: View>(_ view: V, size: NSSize, appearance: NSAppearance.Name, to url: URL, settle: Double = 0.6) {
    let host = NSHostingView(rootView: view.frame(width: size.width, height: size.height))
    host.frame = NSRect(origin: .zero, size: size)
    let win = NSWindow(contentRect: host.frame, styleMask: [.borderless], backing: .buffered, defer: false)
    win.appearance = NSAppearance(named: appearance)
    win.contentView = host
    // Park the window far outside every display: it is "visible" to AppKit/SwiftUI
    // (so lists/forms realize their rows) but no pixel reaches any screen.
    win.setFrameOrigin(NSPoint(x: -30000, y: -30000))
    win.orderFrontRegardless()
    defer { win.orderOut(nil) }
    // Let SwiftUI/AppKit finish layout & async work without ordering the window on screen.
    RunLoop.main.run(until: Date().addingTimeInterval(settle))
    host.layoutSubtreeIfNeeded()
    host.displayIfNeeded()
    let rep = host.bitmapImageRepForCachingDisplay(in: host.bounds)!
    host.cacheDisplay(in: host.bounds, to: rep)
    try! rep.representation(using: .png, properties: [:])!.write(to: url)
    print("wrote", url.lastPathComponent)
}
```

## 6. Risks / open items

1. **Glass in a never-active process.** The captures came from a `.prohibited` process, which is the same situation as the IME (never active), and the glass looked right. Still, watch for "inactive" desaturation on real hardware.
2. **Window level** `CGShieldingWindowLevel()` puts the HUD above everything, including screen-saver and lock-screen shields. Hide the HUD on `NSWorkspace.screensDidSleepNotification` / session resign. If that's a problem, `.popUpMenu + 1` is the conservative alternative, though it may go under Spotlight.
3. Some clients (Terminal, certain Electron and Java apps) return caret rects that are stale or `.zero`. The geometry hides on garbage. The IMK track should also try `firstRect(forCharacterRange:actualRange:)` as a second source.
4. The `TISIconLabels` semantics are undocumented, as noted in §4.4.
5. The icon resembles Apple Translate in spirit (see §4.3).
6. The bundle IDs and suite name used here (`app.duo.inputmethod`, `app.duo.shared`) are placeholders. Align them with the lead's project.yml.

```swift
// MARK: - Input source status (TIS)

enum InputSourceStatus: Equatable {
    case notInstalled, disabled, enabled, selected
    static let bundleID = "app.duo.inputmethod"

    static func current() -> InputSourceStatus {
        let filter = [kTISPropertyBundleID as String: bundleID] as CFDictionary
        let installed = (TISCreateInputSourceList(filter, true)?.takeRetainedValue() as? [TISInputSource]) ?? []
        guard !installed.isEmpty else { return .notInstalled }
        let enabled = (TISCreateInputSourceList(filter, false)?.takeRetainedValue() as? [TISInputSource]) ?? []
        guard !enabled.isEmpty else { return .disabled }
        let current = TISCopyCurrentKeyboardInputSource().takeRetainedValue()
        if let raw = TISGetInputSourceProperty(current, kTISPropertyBundleID) {
            let id = Unmanaged<CFString>.fromOpaque(raw).takeUnretainedValue() as String
            if id == bundleID { return .selected }
        }
        return .enabled
    }

    @MainActor static func openKeyboardSettings() {
        NSWorkspace.shared.open(URL(string: "x-apple.systempreferences:com.apple.Keyboard-Settings.extension")!)
    }
}

// MARK: - Onboarding

enum OnboardingStep: Int, CaseIterable { case welcome, enable, tryIt, done }

struct OnboardingView: View {
    @State private var step: OnboardingStep = .welcome
    @State private var forward = true
    @Environment(\.accessibilityReduceMotion) private var reduceMotion
    @Environment(\.dismissWindow) private var dismissWindow

    var body: some View {
        VStack(spacing: 0) {
            ZStack {
                switch step {
                case .welcome: WelcomeStep()
                case .enable: EnableStep()
                case .tryIt: TryItStep()
                case .done: DoneStep()
                }
            }
            .id(step)
            .transition(stepTransition)
            .frame(maxWidth: .infinity, maxHeight: .infinity)
            .padding(.horizontal, 48)
            .padding(.top, 40)

            HStack(spacing: 12) {
                PageDots(count: OnboardingStep.allCases.count, index: step.rawValue)
                Spacer()
                if step != .welcome && step != .done {
                    Button("Back") { go(-1) }
                        .buttonStyle(.glass)
                }
                Button(step == .done ? "Done" : "Continue") {
                    if step == .done { dismissWindow(id: "onboarding") } else { go(+1) }
                }
                .buttonStyle(.glassProminent)
                .keyboardShortcut(.defaultAction)
            }
            .controlSize(.large)
            .padding(20)
        }
        .frame(width: 620, height: 540)
    }

    private var stepTransition: AnyTransition {
        if reduceMotion { return .opacity }
        return .asymmetric(
            insertion: .move(edge: forward ? .trailing : .leading).combined(with: .opacity),
            removal: .move(edge: forward ? .leading : .trailing).combined(with: .opacity))
    }

    private func go(_ delta: Int) {
        guard let next = OnboardingStep(rawValue: step.rawValue + delta) else { return }
        forward = delta > 0
        withAnimation(reduceMotion ? .easeInOut(duration: 0.2) : .smooth(duration: 0.4)) { step = next }
    }
}
```
